
# Tecnologias Utilizadas

As tecnologias utilizadas no desenvolvimento incluem:

* **Python** – linguagem principal utilizada no desenvolvimento do sistema;
* **Google Meet** – realização de reuniões de alinhamento sobre o projeto e acompanhamento do progresso das atividades distribuídas entre os integrantes do grupo;
* **Câmeras Online DER/SP** – [http://200.144.30.103:8084/](http://200.144.30.103:8084/ "http://200.144.30.103:8084/") – plataforma que disponibiliza as câmeras públicas utilizadas como fonte de dados para o projeto, possibilitando a obtenção de informações sobre as rodovias monitoradas;
* **Word** – elaboração e organização da documentação do projeto;
* **Jira** – gerenciamento do backlog, organização das atividades, acompanhamento do cronograma e controle do desenvolvimento das tarefas, com integração ao Visual Studio Code;
* **Oracle Cloud Infrastructure (OCI)** – utilização de máquina virtual em nuvem para execução contínua do sistema e armazenamento/processamento dos dados capturados pelas câmeras;
* **OpenCV** – processamento e manipulação das imagens obtidas a partir das câmeras;
* **Playwright** – automação e interação com a plataforma das câmeras online;
* **PostgreSQL** – sistema de gerenciamento de banco de dados utilizado para armazenamento e organização dos dados coletados e processados;
* **Git** – controle de versão do código-fonte e gerenciamento das alterações realizadas durante o desenvolvimento;
* **GitHub** – hospedagem do código-fonte, colaboração entre os integrantes e gerenciamento do repositório;
* **Visual Studio Code** – ambiente de desenvolvimento utilizado para programação, organização dos arquivos e integração com as ferramentas do projeto.
