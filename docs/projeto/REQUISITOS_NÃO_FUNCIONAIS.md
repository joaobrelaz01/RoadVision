### ⚙️ Requisitos Não Funcionais — RoadVision

| ID              | Requisito              | Descrição                                                                                                                          |
| --------------- | ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| **RNF01** | Desempenho             | O sistema deverá apresentar desempenho adequado durante os testes.                                                                  |
| **RNF02** | Segurança             | Os dados do sistema deverão ser protegidos contra acessos não autorizados.                                                         |
| **RNF03** | Confiabilidade         | O sistema deverá apresentar resultados consistentes, podendo ocorrer pequenas falhas na detecção.                                 |
| **RNF04** | Manutenção           | O código deverá ser organizado para facilitar correções e melhorias.                                                             |
| **RNF05** | Tempo de processamento | O sistema deverá processar as imagens e vídeos em um tempo aceitável, podendo variar conforme o arquivo e o computador utilizado. |

**Resumo:** requisitos simples, possíveis de cumprir e  **compatíveis com um protótipo acadêmico de iniciantes** .
