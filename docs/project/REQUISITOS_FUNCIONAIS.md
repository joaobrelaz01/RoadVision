
### ⚙️ Requisitos Funcionais — RoadVision

| ID             | Funcionalidade                                   | Descrição                                                                                     |
| -------------- | ------------------------------------------------ | ----------------------------------------------------------------------------------------------- |
| **RF01** | **Acesso às câmeras do DER/SP**          | Receber imagens ou vídeos das câmeras para realizar a análise.                               |
| **RF02** | **Detecção e rastreamento de veículos** | Identificar os veículos nas imagens e acompanhar seu deslocamento.                             |
| **RF03** | **Contagem de veículos**                  | Contabilizar os veículos identificados, separando-os por tipo quando possível.                |
| **RF04** | **Identificação de sentido**             | Identificar o sentido de deslocamento dos veículos na via.                                     |
| **RF05** | **Armazenamento de dados**                 | Armazenar os resultados das análises, como quantidade, tipo e sentido dos veículos.           |
| **RF06** | **Visualização de informações**        | Apresentar os dados coletados de forma simples e visual para facilitar a análise do trânsito. |

**Fluxo básico:**

**Câmera → Detecção → Rastreamento → Contagem → Sentido → Armazenamento → Visualização**
