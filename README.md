# 🚗 RoadVision

Sistema inteligente de monitoramento de rodovias utilizando câmeras do DER/SP e Inteligência Artificial.

## 📌 Sobre o projeto

O RoadVision tem como objetivo monitorar imagens de câmeras de rodovias e utilizar Inteligência Artificial para identificar e analisar veículos automaticamente.

O sistema poderá identificar:

- 🚗 Carros
- 🏍️ Motocicletas
- 🚌 Ônibus
- 🚛 Caminhões
- 📊 Fluxo de veículos
- ↔️ Sentido dos veículos
- 🚨 Possíveis ocorrências

## 🎯 Objetivo

Desenvolver uma solução capaz de auxiliar concessionárias e órgãos responsáveis pelo monitoramento rodoviário, transformando imagens das câmeras em informações úteis para tomada de decisão.

## 🧠 Tecnologias utilizadas

- Python
- OpenCV
- YOLO
- Ultralytics
- Playwright
- NumPy
- Git/GitHub
- DER/SP
